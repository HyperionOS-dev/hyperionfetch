# HyperionFetch 💜
Neofetch wrapper with AppArmor info for HyperionOS — shows system info, AppArmor security status, and HyperionOS branding.
## Features
- Displays standard Neofetch system info
- Shows AppArmor profiles, processes, and modes
- Adds HyperionOS tagline and branding
## Installation

Clone the repo:
```bash
git clone https://github.com/yourusername/hyperionfetch
cd hyperionfetch
chmod +x hyperionfetch.sh
./hyperionfetch.sh
```
### (Optional) Add an alias to replace Neofetch temporarily:
```
alias neofetch="./hyperionfetch.sh"
neofetch
```
